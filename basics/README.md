# Shell, introducción

0-current_working_directory: muestra la ruta absoluta del directorio de trabajo actual.
1-listit: muestra los archivos y carpetas del directorio actual.
2-bring_me_home: cambia el directorio de trabajo al directorio personal del usuario.
3-listfiles: muestra el contenido del directorio actual en formato largo.
4-listmorefiles: muestra el contenido del directorio actual en formato largo, incluidos los archivos ocultos.
5-listfilesdigitonly: muestra los archivos en formato largo, incluidos los ocultos, con los IDs de usuario y grupo en números.
6-firstdirectory: crea el directorio my_first_directory dentro de /tmp.
